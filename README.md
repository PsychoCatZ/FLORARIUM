# FLORARIUM — интернет-магазин комнатных растений

Демонстрационный проект для портфолио: витрина интернет-магазина комнатных
растений с каталогом, фильтрами, корзиной, избранным и тестом-подборщиком
растений. Бэкенда нет — все данные локальные, состояние пользователя
(корзина, избранное) хранится в `localStorage` браузера.

> Это учебно-демонстрационный проект. Компания FLORARIUM, отзывы,
> контакты и показатели вымышлены и приведены только для наглядности.

## Что это за проект

Сайт имитирует небольшой магазин комнатных растений: 18 карточек товара
с честным описанием сложности ухода, освещения, размера и цены, тест
«Подбери растение», работающая корзина с промокодом и оформлением заказа,
избранное и полнотекстовый поиск с фильтрами в каталоге.

Три страницы:

- **`index.html`** — главная: хиро-блок, преимущества, баннер теста,
  подборки «Бестселлеры» и «Новинки», база знаний по уходу, шаги оформления
  заказа, отзывы, FAQ, форма подписки на рассылку.
- **`catalog.html`** — каталог с фильтрами (категория, освещение,
  сложность ухода, размер, цена, безопасность для питомцев), поиском,
  сортировкой и активными чипами фильтров.
- **`favorites.html`** — избранное, синхронизированное через `localStorage`
  со всеми страницами.

## Что реализовано

- **Каталог**: поиск по названию, 4 группы чекбокс-фильтров, слайдер цены,
  сортировка (по популярности/цене/новизне/рейтингу), чипы активных
  фильтров со сбросом, пустое состояние при отсутствии совпадений,
  подстановка фильтра через URL (`catalog.html?category=beginner`).
- **Быстрый просмотр товара**: модальное окно с характеристиками,
  инструкцией по уходу, счётчиком количества и похожими растениями.
- **Корзина**: добавление/удаление, изменение количества, промокод
  (`LISTOK10`, `ЗЕЛЕНЬ15`), подсчёт скидки и итоговой суммы, сохранение
  между перезагрузками страницы.
- **Избранное**: переключение сердечком на любой карточке, отдельная
  страница со списком, счётчик в шапке.
- **Тест «Подбери растение»**: три вопроса (свет, опыт, питомцы) →
  3 подходящих растения, отобранные простым скорингом по атрибутам.
- **Оформление заказа**: валидация имени, телефона, e-mail и адреса
  (адрес обязателен только при курьерской доставке), генерация номера
  заказа и экран подтверждения. Реальная отправка не выполняется —
  это явно указано пользователю в форме.
- **Форма подписки** на главной — с валидацией e-mail и имитацией отправки.
- **Адаптивная вёрстка**: мобильное меню, мобильная панель фильтров,
  сетки товаров, перестраивающиеся от 1 до 4 колонок.
- **Доступность**: семантическая разметка, `<dialog>` для всех модальных
  окон и шторок (нативный фокус-трэп и закрытие по Esc), подписи для всех
  полей форм, видимый фокус на всех интерактивных элементах, alt/aria-label
  на иконках, управление с клавиатуры.

## Стек

Чистые **HTML / CSS / JavaScript** без фреймворков и сборщика:

- Разметка — семантический HTML5, единая структура шапки/подвала/модалок
  на трёх страницах.
- Стили — CSS-переменные (`css/variables.css`), сброс и типографика
  (`css/base.css`), сетка и адаптив (`css/layout.css`), компоненты
  (`css/components.css`). Никаких внешних CSS-фреймворков.
- Логика — набор небольших модулей в общем пространстве имён `window.App`
  (`js/data.js`, `js/storage.js`, `js/icons.js`, `js/cards.js`, `js/ui.js`,
  `js/product.js`, `js/catalog.js`, `js/quiz.js`, `js/checkout.js`,
  `js/favorites.js`, `js/home.js`, `js/main.js`). Обычные `<script>`-теги
  без сборки — проект открывается напрямую в браузере или через любой
  статический сервер.
- Иллюстрации растений — сгенерированные инлайн-SVG (`js/icons.js`), без
  внешних изображений и сетевых запросов.

## Локальный запуск

Сборка не требуется. Есть два варианта:

**1. Открыть файл напрямую**

Дважды кликните `index.html` — все скрипты подключены как обычные теги
`<script>`, ES-модули не используются, поэтому CORS-ограничений браузера
для `file://` не возникает.

**2. Через локальный статический сервер (рекомендуется)**

```bash
python -m http.server 8080
```

и затем откройте `http://localhost:8080` в браузере. Подойдёт любой
другой статический сервер (`npx serve`, расширение Live Server и т.д.).

## Особенности реализации

- Все иллюстрации растений — параметрические SVG-иконки, собранные из
  примитивов (`js/icons.js`), а не растровые изображения, поэтому проект
  не делает ни одного внешнего сетевого запроса.
- Состояние корзины и избранного пересчитывается через единый источник
  правды в `localStorage` (`js/storage.js`) и мгновенно синхронизируется
  между открытыми страницами через колбэки `App.storage.onChange`.
- Промокоды и валидация телефона/e-mail реализованы регулярными
  выражениями без сторонних библиотек.
- Товарные карточки, модалка быстрого просмотра и мини-карточки квиза
  переиспользуют одни и те же функции рендеринга (`js/cards.js`,
  `js/product.js`), чтобы не дублировать разметку.
